# 项目状态手册（双线）

本项目基于openclaw魔改。

为避免上下文过长导致方向混淆，项目固定分为两条线并行推进：

## 1) 本地项目线（运行线）

- 目标：维护与改造当前正在使用的本地系统。
- 优先级：稳定性、可用性、快速修复、不中断业务。
- 约束：以真实运行效果为先，不以对外发布为第一目标。

## 2) 开源发布线（发行线）

- 目标：抽象为可公开发布版本（Cantaur）。
- 优先级：文档完整、部署友好、跨系统安装、无私人信息。
- 约束：不引入本地私有数据、私有路径、私有配置。

## 执行规则

- 每次任务先声明所属线，再实施修改。
- 两条线共享能力方向，但交付物与节奏分离，避免互相污染。
- 若需求同时涉及两条线，先保运行线，再同步发行线文档与模板。
